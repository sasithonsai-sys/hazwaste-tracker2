# ระบบบริหารจัดการของเสียสารเคมีและของเสียอันตราย

เว็บแอปไฟล์เดียว (`index.html`) สำหรับห้องปฏิบัติการ ใช้ลงทะเบียน ติดฉลาก (พร้อม QR Code) ติดตามสถานะ และออกรายงานของเสียสารเคมีตามแบบฟอร์ม **FW-HZW-05 / FW-HZW-06** ไม่ต้องติดตั้งโปรแกรมหรือมีเซิร์ฟเวอร์ เปิดใช้ได้ทั้งบน **คอมพิวเตอร์ แท็บเล็ต และโทรศัพท์**

| คอมพิวเตอร์ | แท็บเล็ต | โทรศัพท์ |
|:---:|:---:|:---:|
| ![PC](docs/images/pc-dashboard.png) | ![Tablet](docs/images/tablet-registry.png) | ![Phone](docs/images/phone-registry.png) |

## คุณสมบัติหลัก

- จำแนกของเสียตามเกณฑ์คัดแยก ของแข็ง (S01–S05) ของเหลว (L01–L20) และชนิดพิเศษ พร้อมออกรหัสและฉลากอัตโนมัติ
- ฉลากมี QR Code พิมพ์บน A4 ได้ และสแกนกลับมาเปิดข้อมูลภาชนะได้
- เพิ่ม/แก้ไข/เติมของเสีย และตรวจเช็คฉลาก-ภาชนะ 6 ข้อ
- แจ้งเตือนเมื่อปริมาณเกิน 80% ของความจุ หรือจัดเก็บนานเกินกำหนด
- คลังของเสียกลาง ติดตามจนถึงการส่งมอบและเลขที่ Manifest
- ออกรายงาน FW-HZW-05 (รายเดือน) และ FW-HZW-06 (ส่งกำจัด) พิมพ์ PDF ได้
- ซิงก์ข้อมูลขึ้น **Google Sheet** ของแต่ละห้อง (เลือกใช้หรือไม่ก็ได้)

## รองรับหลายขนาดหน้าจอ

| อุปกรณ์ | ความกว้าง | การแสดงผล |
|---|---|---|
| โทรศัพท์ | ≤ 640 px | แถบเมนูล่าง ตารางเปลี่ยนเป็นการ์ด หน้าต่างป๊อปอัปเลื่อนขึ้นจากล่าง |
| แท็บเล็ตแนวตั้ง | 641–920 px | เมนูซ้ายแบบไอคอนแคบ เนื้อหาคอลัมน์เดียว |
| แท็บเล็ตแนวนอน / โน้ตบุ๊กเล็ก | 921–1180 px | เมนูซ้ายปกติ เนื้อหาสองคอลัมน์ |
| คอมพิวเตอร์ | > 1180 px | แสดงผลเต็มรูปแบบ (จอใหญ่ ≥ 1600 px ขยายระยะห่างเพิ่ม) |

## เริ่มใช้งาน

### วิธีที่ 1: เปิดไฟล์ตรงๆ
ดาวน์โหลด `index.html` แล้วดับเบิลคลิกเปิดด้วยเบราว์เซอร์ (Chrome, Edge, Safari, Firefox)

### วิธีที่ 2: ใช้ผ่าน GitHub Pages (เปิดจากมือถือได้ทันที)
1. อัปโหลดไฟล์ทั้งหมดขึ้น repository
2. ไปที่ **Settings → Pages**
3. Source เลือก **Deploy from a branch** แล้วเลือก branch `main` โฟลเดอร์ `/ (root)` กด Save
4. รอสักครู่ จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`
5. บนมือถือ เปิดลิงก์แล้วเลือก "เพิ่มไปยังหน้าจอโฮม" จะใช้งานได้เหมือนแอป

> ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้น จึงควรกด "สำรองเป็นไฟล์" หรือซิงก์ขึ้น Google Sheet เป็นประจำ

## เชื่อม Google Sheet (ไม่บังคับ)

แต่ละห้องปฏิบัติการใช้ Google Sheet ของตัวเอง ข้อมูลแยกกันอิสระ

1. สร้าง Google Sheet ใบใหม่ (เปล่าก็ได้)
2. เมนู **Extensions → Apps Script** แล้ววางโค้ดจาก [`apps-script/Code.gs`](apps-script/Code.gs) ทั้งหมด
3. เลือกฟังก์ชัน `initSetup` แล้วกด Run หนึ่งครั้ง (อนุญาตสิทธิ์ตามที่ระบบขอ)
4. **Deploy → New deployment → Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
5. คัดลอกลิงก์ที่ลงท้ายด้วย `/exec`
6. ในแอป ไปที่ **ตั้งค่า & ซิงก์** วางลิงก์ในช่อง Web App URL แล้วกด **บันทึกการตั้งค่า** ก่อน จากนั้นกด **อัปโหลดขึ้นคลาวด์**

ข้อควรจำ

- เมื่อแก้โค้ด `Code.gs` ต้อง Deploy → Manage deployments → เลือก **New version** ทุกครั้ง ไม่เช่นนั้นลิงก์เดิมจะยังรันโค้ดเก่า
- ใน Sheet แก้ข้อมูลตรงๆ ได้ (คอลัมน์ภาษาไทย มี dropdown สถานะและช่องติ๊ก) แล้วกด **ดึง & รวมข้อมูล** ในแอปเพื่อนำกลับมา ฝั่งที่แก้ล่าสุดจะถูกเก็บไว้
- Dashboard และรายงานแสดงเฉพาะข้อมูลของห้องที่ผูกกับ URL นั้น ไม่รวมข้ามห้อง
- ไม่ควรสลับ Web App URL ไปมาระหว่างหลายห้องบนเครื่องเดียว เพราะข้อมูลจะถูกรวมเข้าด้วยกัน

## หมายเหตุ

- ตัวอ่าน QR ในหน้าสแกนโหลดจาก CDN ต้องต่ออินเทอร์เน็ตครั้งแรก ถ้าใช้ไม่ได้ให้กรอกรหัสภาชนะเองในช่องด้านล่าง
- เกณฑ์การคัดแยกอ้างอิงแนวปฏิบัติ มจธ. (ธันวาคม 2566) ควรตรวจสอบกับนโยบายของหน่วยงานตนเองก่อนใช้งานจริง
